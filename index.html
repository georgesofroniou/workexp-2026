Challenge brief · ABC Bank

Everyone has an AI tool.
Almost nobody knows which one to use.

A teenager-friendly walkthrough of the problem you're solving, who you're solving it for, and what "done" looks like.

01 Situation 02 Problems 03 Challenge 04 Who you're helping 05 What it should do 06 Extra task 07 Final presentation

01 — What's the situation?

A bank full of AI tools, used the wrong way

ABC Bank uses lots of AI tools — ChatGPT-style assistants, coding tools, the works. Most employees use AI a lot. But most of them don't feel like they're using it properly.

They get confused about:

  • Which tool to use
  • How to use it well
  • When they're wasting time or money

02 — What problems do people face?

Three apps, no instructions

Think of it like having three different apps that all do similar things — but no one tells you which one is best.

friction/01Picking the right AI tool for each task
friction/02Giving up because tools are too complicated
friction/03Using expensive tools when a cheaper one would do
friction/04Only using basic features and missing better options

03 — Your challenge

Design a platform that helps people decide, fast

You need to design a website (platform) that helps employees quickly figure out:

  • Which AI tool to use
  • How to use it properly
  • What the best option is for their task

04 — Who are you helping?

Four types of users, four sets of friction

01

Business Analysts

Make reports, presentations, and financial analysis.

stuck on → don't know which AI to use for writing vs. analysing

02

Developers (coders)

Write and fix code.

stuck on → need help picking tools for coding tasks

03

Project Managers

Plan projects and communicate with teams.

stuck on → unsure which tool fits admin tasks

04

Non-technical users

Write emails, summaries, basic data work.

stuck on → usually stick to one tool without thinking

05 — What your solution should do

The platform's job, in four moves

move/01Help people choose the right AI tool quickly
move/02Save time making decisions
move/03Avoid wasting money
move/04Help people work faster and better

06 — Extra task (important!)

Talk to two real employees

You'll get to talk to 2 real employees using AI. You must:

  • Prepare at least 5 questions
  • Ask about their struggles
  • Ask how they use AI
  • Ask what confuses them

07 — Final presentation

What you'll need to explain

  1. The problem (what's going wrong)
  2. Your solution (your platform idea)
  3. A prototype (what it looks like / how it works)
  4. How you used AI
  5. What you learned as a team

Simple way to think about it

You're basically building a smart guide

A "smart guide" that tells people how to use AI properly at work. Like:

if you want to write an email → use Tool A
if you want to code → use Tool B

In one sentence: Help people stop guessing and start using the right AI tool the right way.

Need a hand? Ask for creative ideas for your platform, help designing a prototype, or example questions for the Q&A session.
